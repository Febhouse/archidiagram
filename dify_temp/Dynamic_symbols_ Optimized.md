# PRODUCT: DYNAMIC SYMBOLS – SKETCHUP PLUGIN FOR INSTANT SYMBOL ANIMATION
Dynamic Symbols is a lightweight SketchUp plugin developed by Febhouse that lets users animate and customize 2D symbols instantly. The Dynamic Symbols extension is perfect for architects, designers, and educators who visualize diagrams directly inside SketchUp.

---

## 1. CORE FEATURES OF DYNAMIC SYMBOLS
Dynamic Symbols includes 4 core features to help users create instant presentations:

### Dynamic Symbols Feature 1: One-Click Symbol Change
The Dynamic Symbols plugin instantly switches between different symbol shapes with just one click while keeping the symbol’s position, size, and rotation unchanged.
- **Step 1:** Select any Dynamic Symbols object from the toolbar.
- **Step 2:** A dialog box will appear in Dynamic Symbols asking if you want to create a new symbol. Click **Yes** (symbol appears at cursor) or **No** (command canceled).
- **Switching Shapes:** To switch to another Dynamic Symbols shape, just click a different icon on the Dynamic Symbols toolbar.
▶️ **[Watch Video: How to use Dynamic Symbols Feature 1: One-Click Symbol Change](https://www.youtube.com/watch?v=VOl67HeTK8M&t=29s)**

### Dynamic Symbols Feature 2: One-Click Color Change
The Dynamic Symbols extension changes the color of symbols instantly with one click — no need to open complex menus or edit materials manually.
- **Step 1:** Select the Dynamic Symbols object.
- **Step 2:** In the Dynamic Symbols UI, click the **Color Button**.
- **Step 3:** Pick a color, and the Dynamic Symbols system automatically saves the last 5 colors for quick access.
▶️ **[Watch Video: How to use Dynamic Symbols Feature 2: One-Click Color Change](https://www.youtube.com/watch?v=VOl67HeTK8M&t=72s)**

### Dynamic Symbols Feature 3: Create Animated Diagrams
Dynamic Symbols automatically generates animated scenes that bring architectural symbols to life — ideal for diagrams, flowcharts, or architectural storytelling.
- **Step 1:** Select the Dynamic Symbols you want to animate.
- **Step 2:** Click Create Animation within Dynamic Symbols. The Dynamic Symbols plugin generates 3 scenes: Feb_F1, Feb_F2, Feb_F3.
- **Step 3:** In the SketchUp Scenes panel, keep only Feb_F1, Feb_F2, Feb_F3 checked for animation, and uncheck all other scenes.
- **Step 4:** Go to File → Export → Animation, uncheck "Loop to starting scene", and Export the Dynamic Symbols animation.
- **Feature Availability:** The Create Animation feature is included in both Dynamic Symbols Free and Dynamic Symbols Pro versions, but Dynamic Symbols Pro allows you to work with unlimited symbols.
- **💡 Pro Tip for Dynamic Symbols:** After exporting the Dynamic Symbols animation from SketchUp, use video editing software (like CapCut, Premiere) to smoothen the transition or create a continuous looping animation.
▶️ **[Watch Video: How to use Dynamic Symbols Feature 3: Create Animated Diagrams](https://www.youtube.com/watch?v=XDDJ7J3_zsE&t=36s)**

**What is the Dynamic Symbols plugin used for?**
Dynamic Symbols is a SketchUp plugin providing a comprehensive library of graphic diagram symbols for architectural presentations. Dynamic Symbols allows users to easily drag, scale, and customize symbols directly within the 3D workspace.

**Can I use the Dynamic Symbols plugin for commercial projects?**
Yes, both the Dynamic Symbols Free and Dynamic Symbols Pro/Studio versions are fully licensed for commercial work and client presentations.

**What is the difference between Dynamic Symbols Studio and Dynamic Symbols Pro versions?**
Both versions offer exact same features. Dynamic Symbols Studio is an annual subscription ($12/year) with auto-updates via the Extension Warehouse. Dynamic Symbols Pro is a lifetime license ($29 one-time) with manual updates via Gumroad.

**Where is my License Key for the Dynamic Symbols Studio version?**
A License Key is not needed for the Dynamic Symbols Studio version. The Dynamic Symbols Studio license is automatically linked to the email address associated with the SketchUp account.

**Can I use the Dynamic Symbols plugin on multiple computers?**
For Dynamic Symbols Studio, log into the SketchUp account on the new computer and install from the Warehouse. For Dynamic Symbols Pro, the lifetime license allows installation on multiple personal machines, but concurrent use or sharing of Dynamic Symbols is prohibited.

### 7.2. Technical & Troubleshooting FAQs

**Why does my exported Dynamic Symbols animation flicker or pop up without continuous motion?**
This happens when SketchUp’s scene transitions are disabled. To fix the Dynamic Symbols animation, go to Window > Model Info > Animation and check the "Enable scene transitions" box.

**I received an "SSL_connect" activation error with Dynamic Symbols. How do I fix this?**
This error indicates a network or firewall is blocking the connection to verify the Dynamic Symbols license. To fix the Dynamic Symbols activation: 1) Ensure system date/time are accurate. 2) Try a different network (like a mobile hotspot) for the initial activation. 3) Verify an official version of SketchUp is used.

**I installed the Dynamic Symbols plugin, but the interface isn't showing. What should I do?**
Ensure SketchUp 2020 or newer is running, and verify that “Extensions” are enabled in the SketchUp Preferences before using Dynamic Symbols.

**Can I use the Dynamic symbols plugin if I am using an unofficial or non-genuine version of SketchUp?**
It depends on the version of the plugin:
* Dynamic Symbols Pro & Standard: These versions can still be installed and will function normally. 
* Dynamic Symbols Studio: This version cannot be used on unofficial SketchUp releases. The Studio version requires a valid Trimble account login for system integration and licensing, which is typically disabled or unsupported in non-genuine SketchUp versions.

**How do I cancel my subscription or free trial for the SketchUp Dynamic Symbols Studio extension? Will I be charged automatically after the trial ends?**
If you are currently using the free trial of the Dynamic Symbols Studio extension, please rest assured that the SketchUp Extension Warehouse will not automatically charge you or convert your trial into a paid subscription when it ends. Once the trial expires, the extension will simply stop running unless you choose to manually purchase a license. However, if you want to ensure everything is cleared or wish to remove the plugin right away for peace of mind, you can choose one of the following methods:
- Method 1: Manage or Uninstall directly inside SketchUp (Recommended)
  + Open SketchUp on your computer.
  + Go to the top menu and select Extensions > Extension Manager (or Window > Extension Manager).
  + Find Dynamic Symbols Studio in the list.
  + Click Manage and choose Uninstall to completely remove it, or toggle the switch to disable it.
- Method 2: Check status on Extension Warehouse
  + Visit the Extension Warehouse website.
  + Sign in with your Trimble ID (the account used to download the extension).
  + Click on your profile icon in the top-right corner and select My Extensions (or Manage Subscriptions).
  + Locate the Dynamic Symbols Studio extension to check its current trial status or cancel any active plans.

- For Dynamic Symbols Pro: Open SketchUp > Extension Manager > Click “Install Extension” and select the extracted .rbz file.

**I just purchased the Dynamic Symbols Studio version on the Extension Warehouse. How do I download and install it?**
Please note that Dynamic Symbols Studio is the Pro/Premium version of our extension. Since you purchased it directly through the SketchUp Extension Warehouse, your license is automatically linked to your Trimble account. You do not need a separate download link; you can install it using one of the two methods below:

**I tried to download Dynamic Symbols from the Extension Warehouse but couldn't. Is this because I am using an unofficial version of SketchUp?**
Not being able to download the plugin directly from the Extension Warehouse link is not necessarily due to your SketchUp version, but rather because the website requires you to log in with a Trimble account. Depending on your needs and your current SketchUp setup, you can choose one of the following options:

**Why is there only the "Dynamic Symbols Pro" version on SketchUcation, and no "Studio" version?**
On the SketchUcation platform, both the annual subscription and the lifetime license are distributed under the single name Dynamic Symbols Pro. The only difference is the duration you choose at checkout: a 1-Year License (366 days) or a Lifetime License (Unlimited days). The installation file and core features are exactly the same.

**I purchased Dynamic Symbols Pro on SketchUcation, how do I activate my license?**
First, make sure you have downloaded and installed the SketchUcation Tools plugin from their homepage. To activate your license (for both the 366-day and Unlimited-day options), open the About window in Dynamic Symbols Pro, or go to Extensions > Dynamic Symbols Pro > License. Click the Activate button and select the .scflicense file that was emailed to you upon purchase.

**Why is the version of Dynamic Symbols Pro on SketchUcation and Gumroad higher than the version on the Extension Warehouse?**
Yes, that is correct. Updates are released faster on SketchUcation and Gumroad. The official SketchUp Extension Warehouse has a very strict and time-consuming review process for every new update.
