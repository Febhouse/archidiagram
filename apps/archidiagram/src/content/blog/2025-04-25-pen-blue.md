# Pen blue for Sun Diagram - Style 03

**Pen blue** is custom style for Sun Path — softer colors, clean lines, and perfect for client presentations.

The Sun Path from **Sun Diagram** is vector-based, so you can fully customize its look using SketchUp **Styles**.

Sun Diagram STYLE templates have now been integrated directly inside the Sun Diagram plugins — no need for separate downloads anymore.

If you’re using the latest version of **Sun Diagram,** you already have access to these styles in the plugin panel.
