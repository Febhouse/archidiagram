## **STEP 1: Create a 3D model in SketchUp**

https://www.youtube.com/watch?v=Ir4KS6us0HE

1. Open **SketchUp** and model the objects you want to analyze (e.g., a room and trees).
2. Keep the model **simple**, using only essential elements like walls and simplified trees (e.g., spheres on top of cylinders).
3. Check and set the **unit** of your model to **meters**:
    
    
    - Go to **Window &gt; Model Info &gt; Units**
4. Export the model as an **STL file**:
    
    
    - **File &gt; Export &gt; 3D Model**
    - Select **STL format** and ensure the unit is set to **meters**.

<a id="step2"></a>
## **STEP 2: Import the Model into Rwind Simulation**

https://www.youtube.com/watch?v=Ir4KS6us0HE

1. Open **Rwind Simulation** (trial version available)
2. Create a **new project**, name it, and select a save location.
3. Import the **STL file** and ensure the unit is **meters**.
4. Adjust the **simulation box**:
    
    
    - Reduce its size to optimize calculation time.
    - If studying only horizontal airflow, adjust the box height accordingly.
5.

<a id="step3"></a>
## **STEP 3: Set Up the Simulation in Rwind**

https://www.youtube.com/watch?v=Ir4KS6us0HE

1. Go to **Edit Simulation** and adjust settings:
    
    
    - Set **inlet wind speed** (e.g., 5 m/s).
    - Adjust **mesh density** (20% for a balance between speed and accuracy).
2. Click **OK**, then **Calculate Results**.
3. Wait for the simulation to complete.

<a id="step4"></a>
## **STEP 4: Visualizing Airflow**

https://www.youtube.com/watch?v=Ir4KS6us0HE

1. Select **Flow Field Quantities** and choose the **XY plane**.
2. Choose a **visualization type**:
    
    
    - **Vector** (arrows indicating wind direction and speed).
    - **Streamline** (continuous lines showing airflow path) → Recommended.
3. Adjust streamline **density, size, and visibility**.
4. Set the view to **top-down (plan view)**.
5. Disable **background and grid textures**.
6. Export a **10-second animation**:
    
    
    - Click **Start**, then select **Flow Animation**.
    - Choose a **save location** and export the video.

<a id="step5"></a>
## **STEP 5:Post-Processing in Photoshop**

https://www.youtube.com/watch?v=Ir4KS6us0HE

1. Open **Photoshop** and import the video.
2. Enable the **Timeline** panel.
3. Add **PNG images** (furniture, trees, etc.) to enhance realism.
4. Adjust **opacity** to blend elements with the background.
5. Draw **wall outlines** for clarity.
6. Replace simple tree shapes with **PNG tree images**.
7. Align layers with the **timeline** and extend them to match the video duration.
8. Crop the video to focus on **key moments**.
9. Export the **final processed video**.
