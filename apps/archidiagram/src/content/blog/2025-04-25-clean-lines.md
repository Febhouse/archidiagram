# Clean Lines for Sun Diagram (Style 01)

![Clean line -cover](/images/2025/04/STYLE-1-COVER-1-1.webp)

The **Clean Line Style** for Sun Diagram is based entirely on 3D sun path vectors. Because it relies on crisp, clean lines rather than heavy graphics, it is perfect for technical documentation and professional client presentations.

The Sun Path generated by the **Sun Diagram** extension is vector-based, which means you have full control to customize its look directly using SketchUp **Styles**.

> **Good News:** Sun Diagram STYLE templates have now been integrated directly inside the Sun Diagram plugin! You no longer need to download these styles separately.

If you’re using the latest version of **Sun Diagram,** you already have one-click access to these styles right in the plugin panel.
