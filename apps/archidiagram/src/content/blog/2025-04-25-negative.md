# Negative Style for Sun Diagram (Style 02)

![Negative Style -COVER](/images/2025/04/STYLE-2-COVER-1.webp)

The **Negative Style (Inverted)** is a custom look I designed for the Sun Path. Featuring a stark dark background with clean white lines, it is perfect for dark mode workflows, evening presentations, or dramatic presentation boards.

> **Good News:** Sun Diagram STYLE templates have now been integrated directly inside the Sun Diagram plugin! You no longer need to download these styles separately.

If you’re using the latest version of **Sun Diagram,** you already have one-click access to these styles right in the plugin panel.
